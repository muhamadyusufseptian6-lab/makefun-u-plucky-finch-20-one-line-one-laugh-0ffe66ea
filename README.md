Entry for the make.fun bounty **One Line, One Laugh** (`u-plucky-finch-20-one-line-one-laugh-0ffe66ea`): one funny line of at most 200 characters, judged pairwise by an AI judge.

## The line

> My Roomba did 412 laps of the same 3-metre hallway, unionized, and now the dust bunnies pay its dues.

One line, 101 characters — a Roomba that works so hard it unionizes, then flips the power dynamic so the dust itself pays up.

## How it works

`main.ts` (Node 22, standard library only, deterministic) writes the line above to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no secrets, no input files — the same line every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-laugh-out node main.ts
cat /tmp/one-laugh-out/entry.txt
```
